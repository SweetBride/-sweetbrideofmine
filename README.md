# Sweet Bride of Mine website

Free static website for GitHub Pages. Edit `index.html` for words/prices/contact details and `style.css` for design.

## Important: Add your real photos

The design intentionally shows **photo placeholders**, because your original wedding photographs weren't attached in this conversation. Upload your own JPG photos into the `images` folder with these exact filenames:

- `ceremony.jpg`
- `reception.jpg`
- `gallery-1.jpg`
- `gallery-2.jpg`
- `gallery-3.jpg`

The site will automatically show them in place of the placeholders. You can use the same photo more than once if needed. Use photos you own or have permission to publish.

## Upload to GitHub from iPhone

1. Download and unzip the website ZIP in the iPhone Files app.
2. Open your `SweetBride/sweetbrideofmine` repository on GitHub.
3. Choose **Add file → Upload files** (if unavailable on mobile, choose **Request Desktop Website** in Safari). Upload `index.html`, `style.css`, `script.js`, and `README.md` to the **repository root**, not inside a parent folder. Commit the changes.
4. To upload photos later, open/create the `images` folder and upload the five JPG files.
5. Under repository **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)` and **Save**. Your free GitHub Pages URL should be `https://sweetbride.github.io/sweetbrideofmine/` after publishing.
6. After publishing works, under **Settings → Pages → Custom domain**, enter `sweetbrideofmine.com.au` and save. Follow GitHub's current DNS instructions and configure the matching DNS records in Crazy Domains. Wait for DNS to propagate, then enable **Enforce HTTPS** when available. Don't change DNS until the site is publishing.

## Contact form

The enquiry form uses FormSubmit (a third-party service) to send form submissions to `sweetbridestyling@gmail.com` with no server or hosting fee. **You must verify/activate the destination email** when FormSubmit sends the first confirmation. Test the form yourself before sharing the website. Email and telephone links work independently.

## Notes

Pricing and copy are editable. Domain registration with Crazy Domains is not free; GitHub Pages hosting is free for public repositories, subject to GitHub terms and limits.
